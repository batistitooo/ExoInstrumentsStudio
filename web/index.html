              Real exoplanet research

              This searches real observations, not simulated ones. A light curve is fetched from MAST, detrended, searched with the same blind box least squares detector the simulator uses, vetted against the ways a transit can be something else, and checked against what is already known. Every run is kept, found or not, because the dataset is the point.

              The two minute targets have all been through the mission's own pipeline, so a search there mostly recovers what is already catalogued. What is genuinely under searched is long periods and single transits, which need three transits to be found and often only show one.
